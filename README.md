## 🌷 Mis proyectos destacados

### 🎀 01. LockrBox — Sistema de gestión de inventarios y pedidos con locker inteligente

<img src="https://img.shields.io/badge/Java-FFE0EF?style=flat-square&logo=openjdk&logoColor=9C4776"/>
<img src="https://img.shields.io/badge/PostgreSQL-E8D9FF?style=flat-square&logo=postgresql&logoColor=62458B"/>
<img src="https://img.shields.io/badge/ESP32-D7F5E7?style=flat-square&logo=espressif&logoColor=276749"/>

**LockrBox** es un sistema web que permite gestionar productos, inventarios y pedidos, facilitando que los clientes realicen compras en línea y recojan sus pedidos mediante un locker inteligente.

**Características principales:**

- 🛍️ Gestión de productos, inventarios y pedidos.
- 🗃️ Persistencia de datos mediante PostgreSQL.
- 📱 Generación de códigos QR para la recolección de pedidos.
- 🔐 Integración con ESP32 para controlar la apertura del locker.
- 🖥️ Panel administrativo y flujo de pedidos.
- 🧩 Comunicación entre el sistema web y el hardware.

**Tecnologías:** Java, Jakarta Servlets, JSP, JDBC, PostgreSQL, ZXing, Maven y ESP32.
