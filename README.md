## 🌷 Mis proyectos destacados

### 🎀 01. LockrBox — Smart Locker System

<img src="https://img.shields.io/badge/Java-FFC7E8?style=flat-square&logo=openjdk&logoColor=66334F"/>
<img src="https://img.shields.io/badge/PostgreSQL-DCCBFF?style=flat-square&logo=postgresql&logoColor=493B69"/>
<img src="https://img.shields.io/badge/ESP32-BFEBD7?style=flat-square&logo=espressif&logoColor=245C4A"/>

Sistema web de gestión de inventarios y pedidos con un **locker inteligente** para facilitar la compra y recolección de productos.

**Características principales:**

- 🛍️ Administración de productos, inventario y pedidos.
- 🗃️ Backend conectado a una base de datos PostgreSQL.
- 📱 Generación de códigos QR para recoger pedidos.
- 🔐 Apertura automatizada del locker mediante integración con ESP32.
- 🧁 Panel administrativo y flujo de pedidos.

**Tecnologías:** Java, Jakarta Servlets, JSP, JDBC, PostgreSQL, ZXing, Maven y ESP32.
